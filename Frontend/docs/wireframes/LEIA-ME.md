# Wireframes

Coloque aqui os wireframes das telas exportados como imagem (PNG/JPG) ou PDF — um arquivo por
tela, com nomes descritivos, por exemplo:

- `01-login.png`
- `02-lista-os.png`
- `03-detalhe-os.png`
- `04-nova-os.png`
- `05-clientes.png`
- `06-cliente-form.png`

O Claude Code abre esses arquivos na Fase 1 e os usa como referência de layout. As regras de
`../TELAS.md` e do SRS continuam valendo mesmo que o wireframe mostre algo diferente.
